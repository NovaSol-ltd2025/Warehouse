# NOVASOL Warehouse & Delivery Management

ระบบควบคุมวัสดุอุปกรณ์คลังสินค้าและกระจายส่งสาขา — ห้างหุ้นส่วนจำกัด โนวาโซล

- **โค้ด**: เก็บที่ GitHub (repo นี้)
- **ข้อมูล**: เก็บใน Google Sheet ของคุณ ผ่าน Google Apps Script (`apps-script/Code.gs`)
- **เว็บ**: Vite + React ติดตั้งบน GitHub Pages อัตโนมัติ (`.github/workflows/deploy.yml`)

## ตั้งค่า Google Sheet เป็นฐานข้อมูล (ครั้งเดียว)

1. เปิด Google Sheet → **ส่วนขยาย → Apps Script** → วางโค้ดจาก `apps-script/Code.gs` แล้วบันทึก
2. เลือกฟังก์ชัน `setupDatabase` → **เรียกใช้** → กดยอมรับสิทธิ์ → จดค่า **API Token** ที่แสดง
3. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   ดำเนินการในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน (Anyone)** → คัดลอก URL ที่ลงท้าย `/exec`
4. เปิดแอป → ปุ่ม **Google Sheet** มุมบนขวา → วาง URL + Token → **บันทึกและเชื่อมต่อ**
   (ครั้งแรกระบบจะสร้างข้อมูลตัวอย่างเริ่มต้นในชีตให้อัตโนมัติ)

แก้โค้ด `Code.gs` ภายหลังต้อง Deploy เป็น **เวอร์ชันใหม่** ทุกครั้งจึงจะมีผล

### โครงสร้างในชีต

แท็บ `DB_items`, `DB_suppliers`, `DB_branches`, `DB_branch_orders`, `DB_purchase_orders`, `DB_movements`, `DB_branch_demands`
(1 แถว = 1 รายการ) — คอลัมน์ `id`, `updatedAt`, `_json1.._json8` คือข้อมูลจริงที่แอปอ่าน
ส่วนคอลัมน์ถัดไปเป็นข้อความสรุปไว้ให้คนอ่าน/กรอง/ทำรายงาน **แก้ในชีตแล้วจะไม่มีผลกับแอป** ให้แก้ผ่านแอป

### ความปลอดภัย (อ่านก่อนใช้งานจริง)

- Web App เปิดให้ "ทุกคน" เรียกได้ แต่ทุกคำขอต้องมี API Token ถูกต้อง ไม่มี Token = อ่าน/เขียนไม่ได้
- Token ที่ผู้ใช้กรอกในแอปเก็บในเบราว์เซอร์เครื่องนั้น ๆ ถ้าตั้งเป็น `VITE_SHEETS_API_TOKEN` ตอน build
  ค่าจะถูกฝังในไฟล์เว็บ **ใครเปิดเว็บก็เห็น** — ถ้า repo/เว็บเป็นสาธารณะ อย่าฝัง Token ให้ผู้ใช้กรอกเอง
- เปลี่ยน Token ได้ที่เมนู **📦 NOVASOL → สร้างรหัส API Token ใหม่** ในชีต
- รูปภาพ/ลายเซ็นที่เป็น data URL ถูกเก็บในเซลล์ได้สูงสุดราว 320,000 ตัวอักษรต่อรายการ

## รันบนเครื่อง

```bash
npm install
cp .env.example .env.local   # ไม่บังคับ ใส่ URL/Token เริ่มต้น
npm run dev                  # http://localhost:3000
npm run lint                 # ตรวจ TypeScript
npm run build                # ไฟล์เว็บอยู่ที่ dist/
```

## Deploy ขึ้น GitHub Pages

Settings → Pages → Source: **GitHub Actions** แล้ว push ไป `main` เว็บจะ build และเผยแพร่ให้เอง

## หมายเหตุ

- ยังไม่ได้ตั้ง URL/Token แอปจะทำงานในโหมดทดลองด้วยข้อมูลตัวอย่าง (ไม่บันทึกถาวร)
- ข้อมูลซิงก์ทุกเครื่องด้วยการตรวจชีตทุก ~20 วินาที และเมื่อสลับกลับมาที่แท็บ (ไม่ใช่ real-time ทันที)
- ถ้ามีผู้ใช้แก้ข้อมูลพร้อมกันหลายคน การเขียนจะถูกจัดคิวที่ชีต รายการที่แก้ชนกันใช้ค่าของคนที่บันทึกทีหลัง
